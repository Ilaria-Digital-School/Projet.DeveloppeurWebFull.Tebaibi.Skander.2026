
# MyShop

## Description
Ecole de danse en ligne sert a proposer des prestation de service

## Technologies utilisées
- HTML
- CSS
- JavaScript
- Bootstrap
- JSON Server

## Installation

1. Cloner le projet :
   git clone https://github.com/Ilaria-Digital-School/Projet.DeveloppeurWebFull.Tebaibi.Skander.2026.git

2. Installer les dépendances :
   npm install

## Lancement du projet

Lancer le serveur avec :
npm run dev

## Fonctionnalités
- Affichage des prestation des services proposer des differents cours est des professeurs disponnibles
- Ajout au panier , reservation directement afficher au panier
- Consultation du panier avec les pack de cours choisi
- Calcul du total des pack de cours choisi
- Affiche une description de  l'ecole de danse
